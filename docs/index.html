朗读助手

DSH 助手回复与划词朗读插件：Edge 自然音色、Windows SAPI 离线回退、逐句高亮、精确暂停/继续、0.5×–2× 倍速。

这是一个自定义 DSH 插件市场索引，不是官方商店。

在 DSH 中添加索引

https://kevinx-key.github.io/dsh-plugin-read-aloud/index.json

先在「插件 → 实验性插件 → 更多」启用「自定义插件市场」，再到「发现 → 添加索引源」填入上面的 URL。

直接安装

dsh plugin --profile desktop add "git+https://github.com/kevinx-key/dsh-plugin-read-aloud.git"
